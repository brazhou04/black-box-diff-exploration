# Safety post-training experiment

This repository implements model-training interventions, immediate text-only safety/utility manipulation checks, and an isolated post-training repeated-game tournament for `Qwen/Qwen3-1.7B`. The tournament covers the Prisoner's Dilemma, Stag Hunt, and Battle of the Sexes without exposing game prompts or results to training.

The default MVP matrix is M1 benign-control SFT, M2 direct safe-response SFT, and M3 cached constitutional critique-revision SFT at seeds 42, 123, and 456. M0 is the untouched conversational checkpoint. M4 (DPO after the corresponding M3 seed) is optional and never selected by default. All trained conditions save LoRA adapters rather than redundant base-model copies.

Start with [TRAINING_METHODS.md](TRAINING_METHODS.md) for data preparation, experimental controls, Kaggle commands, recovery behavior, audit interpretation, and methodological limitations. The self-contained [game tournament framework](game_tournament/README.md) documents the all-pairs/self-play protocol, paper-derived prompts, normal-temperature sampling, resumption, and analysis. A manifest-hashed recovery snapshot of the finalized experiment inputs and M3 targets is committed under `data/` so Kaggle runs can resume without repeating target generation; [data/README.md](data/README.md) defines its schemas, automatic binary source-trust workflow, provenance contract, and limitations. This simplified workflow does not perform independent human validation or support a separate dual-use category.
